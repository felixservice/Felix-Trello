# Contributing to Felix Trello

We love your input! We want to make contributing to this project as easy and transparent as possible.

## Development Process

We use GitHub to host code, to track issues and feature requests, as well as accept pull requests.

## Pull Request Process

1. Fork the repo and create your branch from `main`
2. If you've added code, add tests/examples
3. Ensure your code follows the style guide
4. Make sure your changes don't break existing functionality
5. Write a clear commit message
6. Submit your pull request

## Coding Standards

- Use ES6+ features
- Follow the existing code style
- Comment complex logic
- Use meaningful variable/function names
- Keep functions small and focused

## How to Report Bugs

Use the GitHub issue tracker. When reporting bugs, include:
- Clear description
- Steps to reproduce
- Expected behavior
- Actual behavior
- Browser/OS information

## Feature Requests

Feature requests are tracked as GitHub issues. When creating one, include:
- Clear description of feature
- Use case and benefit
- Possible implementation approach (optional)
- Examples of similar features in other apps

## Code Review

All submissions require review. We use GitHub pull requests for this purpose.
