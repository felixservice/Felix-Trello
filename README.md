# ✨ Felix Trello - Premium Task Management System

A modern, high-quality Trello-like project management web application built with React, featuring a sleek UI with glassmorphism design, dark mode support, and powerful task management features.

## 🚀 Features

### Core Features
- ✅ Create, edit, and delete boards
- ✅ Organize with lists/columns within boards
- ✅ Manage tasks/cards within lists
- ✅ Drag-and-drop cards between lists (smooth animations)
- ✅ Detailed card modal with rich editing
- ✅ Priority system (Low, Medium, High)
- ✅ Due dates for tasks
- ✅ Color-coded labels/tags
- ✅ Checklist functionality
- ✅ Activity log tracking

### Design & UX
- 🎨 Modern glassmorphism UI
- 🌓 Dark mode & light mode toggle
- 📱 Fully responsive (mobile, tablet, desktop)
- ✨ Smooth animations & transitions
- 🔍 Search functionality
- 🎯 Professional, premium feel

### Advanced Features
- 💾 Local storage persistence
- 🎯 Smart state management with Zustand
- ⌨️ Keyboard shortcuts support
- 📊 Board overview with stats
- 🏷️ Label system with custom colors

## 🛠️ Tech Stack

- **Frontend Framework**: React 18
- **State Management**: Zustand
- **Styling**: Tailwind CSS
- **Drag & Drop**: react-beautiful-dnd
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Date Utilities**: date-fns

## 📦 Installation

1. Clone the repository
```bash
git clone https://github.com/felixservice/Felix-Trello.git
cd Felix-Trello
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Build for production
```bash
npm run build
```

## 🎮 Usage

### Creating a Board
1. Click the "+" button in the sidebar
2. Enter a board name
3. Click "Create"

### Managing Lists
1. Click "Add List" at the end of your board
2. Enter a list name
3. Manage with edit/delete buttons

### Managing Cards
1. Click "Add Card" in any list
2. Enter a card title
3. Click on a card to open the detailed editor
4. Add description, due date, labels, checklist items, etc.

### Drag & Drop
- Simply click and drag cards between lists
- Smooth animations show the movement

## 🎨 Customization

### Color Scheme
Edit `tailwind.config.js` to customize colors.

### Labels
Create labels with custom colors from the card editor.

## 💾 Data Persistence

All data is automatically saved to browser localStorage. Your boards, lists, and cards will persist between sessions.
